# Make Knowledge Cards

## 概述

把一篇文章压缩成 5～8 张知识卡片，每张卡片承载且只承载一个知识点，全部内容来自原文，不补写、不注水。

核心约束一句话：**卡片数量服从原文的信息量，而不是服从"5～8"这个区间。**

## 输入边界

| 输入形式 | 处理方式 |
| --- | --- |
| 用户直接粘贴的正文 | 直接使用 |
| 本地 `.md` / `.txt` 文件路径 | 用 Read 读取全文，只读一次 |
| 网页链接、PDF、docx、图片、音频 | 不支持。明确说明限制，请用户粘贴正文或另存为 `.md` / `.txt` 后重试 |
| Anki 导出、图形界面操作 | 不支持，不承诺生成 `.apkg` |

遇到不支持的输入不要尝试变通抓取（不抓网页、不解析 PDF）。一句话说明限制，给出可行的替代输入方式即可。

## 工作流

### 步骤 1：取正文并剥离噪声

1. 按上表获取全文。
2. 剥离非正文内容：站点导航、作者简介、版权声明、广告、订阅提示、"相关阅读"、评论区、页脚。
3. 统计正文字数：文件输入用 `wc -m` 统计字符数（英文用 `wc -w` 统计词数），粘贴文本按字符数量级估算。结果保留到百位并标注"约"，不要目测估数。
4. 记下全文主标题（没有则标记"原文未提供标题"）。

剥离噪声是删减，不是改写。**除噪声外，不得删除或改写原文的论述**。

若正文不足约 300 字，或通读后找不到一个可独立成卡的知识点，直接进入步骤 5 的"信息不足"分支，不要硬拆句子凑数。

### 步骤 2：抽取候选知识点

逐段问一句"这段在教读者什么"，把答案记成候选点。判定"重要"的四条标准，满足任意一条即可入选：

1. **定义**：给出了核心概念、术语、指标的含义或构成。
2. **机制**：给出了原理、因果链、"为什么会这样"。
3. **方法**：给出了可执行的步骤、操作顺序、判断标准、参数取值。
4. **反直觉事实或边界**：给出与常识相反、容易被做错、或在什么条件下不成立的信息。

明确丢弃以下内容：

- 铺垫性背景、行业历史叙事、时间线铺陈（除非本身即知识点）。
- 作者的个人经历、情绪、立场表达、对读者的呼吁。
- 同一结论的不同措辞重述（属重复，见步骤 3）。
- 只作点缀、不承载结论的数字。
- 营销话术、导流文案、免责声明。
- 结尾的总结段、展望段、号召段。这类段落通常只是前文重述，不单独成卡；仅当它给出前文没有出现过的综合判断时，才单独成卡。

识别观点型文章时注意：文章里的事实陈述与作者主张要分开记。评论、预测、判断属于主张，不要当成事实写进卡片（标注方式见步骤 4）。

若候选点超过 12 个，先按"能否独立回答一个问题"排序，保留信息密度最高的前 8 个。

### 步骤 3：原子化与去重

这是决定卡片质量的关键步骤，逐条执行：

1. **一卡一点**：一个知识点指一个可以独立陈述、独立提问的结论。两个结论即使同属一段，也拆成两张卡。
2. **合并重复**：同一结论在多处出现，合并为一张，采用信息最完整的表述，其余位置只作解释素材。
3. **处理层级关系**：上位概念单独成卡，下位细节并入该卡的"简明解释"，不要为父子关系各出一张卡——那会让两张卡讲同一件事。
4. **区分"并列"与"重复"**：同一主题下的两个不同侧面（例如两个不同的失败原因）属于并列，各自成卡；同一侧面的两种说法属于重复，合并。
5. **现象与机制不重复写因果**：现象卡只写"是什么、怎么表现出来"，机制卡写"为什么"。因果解释只写在机制卡里一次，不要在两张卡的解释中重复同一段推理。
6. **并列枚举合并为清单卡**：原文给出的一串并列项（命令动作表、参数清单、检查项列表）不逐项成卡——逐项会产出信息量极低的多张卡。合并为一张"清单卡"，核心知识写明这组并列项共同的用途，简明解释里列出各项差异要点。仅当某一项自身构成独立且重要的知识点（例如两个相近动作之间的取舍）时，才单独拆出。
7. 去重后清点数量，进入步骤 4。

### 步骤 4：撰写卡片

每张卡片固定四个字段，字段名不改、顺序不变。

卡片语言与原文语言保持一致：原文为英文则卡片用英文写，字段标签随语言调整（Title / Key point / Explanation / Example / Self-check）；用户明确指定输出语言时以用户指定为准。

**标题**

- 8～16 字，直接陈述知识点本身。
- 用名词性短语或判断句，例如"间隔重复依赖遗忘曲线"。
- 禁止"第一点""关于 XX""核心要点一"这类序号式标题——标题必须可独立阅读。

**核心知识**

- 一句话结论，不超过 40 字。
- 尽量复用原文的术语和措辞，便于读者对回原文。
- 只写结论，不写推导。
- 标注信息来源的性质。原文以事实陈述为主时不必逐张加前缀；当原文把事实与作者主张混在一起（评论、分析、预测类文章）时，必须启用前缀，让读者一眼分清哪些是原文证据、哪些是作者判断：
  - 原文的事实、研究结论、数据 → 以 `事实：` 开头。
  - 作者的判断、预测、评价、因果推断 → 以 `作者主张：` 开头，并在简明解释末尾补一句说明该判断在原文中是否给出论据（例如"原文未提供量化验证"）。
  - 前缀不计入 40 字上限。

**简明解释**

- 2～4 句，讲清三件事：是什么、为什么成立、在什么条件下适用或不适用。
- 原文未说明的"为什么"或"边界"不要自行补全，宁可只写原文给出的部分。

**例子 / 自测**

- 二选一，由原文素材决定：
  - 原文有具体案例、数据、场景 → 用原文的例子，可压缩措辞，**不得替换为自造案例**。
  - 操作类文章给出的命令、参数、配置片段 → 优先直接引用原文命令作为例子，比改写为自测题更有用。
  - 原文既无案例也无操作素材 → 写一道针对该知识点、可自答的问答题，并附一句参考答案要点，答案同样不得超出原文。
- 用 `例子：` 或 `自测：` 标注类型，让读者知道在读哪一种。

### 步骤 5：数量决策（硬性规则）

按去重后的有效知识点数量 N 决定输出：

| 情况 | 处理 |
| --- | --- |
| N ≥ 5 | 输出 5～8 张。超过 8 个时按信息密度取舍，不输出 9 张以上 |
| 3 ≤ N < 5 | 输出 N 张，并在开头注明"原文有效知识点约 N 个，未凑足 5 张" |
| N < 3 | 不出卡片。说明信息量不足的具体原因，列出 1～2 个可提取的要点，建议补充材料 |

字数只作粗筛，不作数量上限：500 字以内通常 1～3 张，500～1500 字通常 3～5 张，1500～4000 字通常 5～7 张，4000 字以上 6～8 张。教程、参数清单、检查表这类高信息密度文本可以超出所在区间的提示值，但总数不超过 8 张，且超出的每一张都必须能一句话说明为何不可合并。

**严禁**为凑数而拆句、换措辞重述、补充原文之外的背景、把一句话拆成两张卡。

### 步骤 6：输出前自检

逐条核对，任一条不通过就回到对应步骤修正：

| # | 检查项 | 不通过的处理 |
| --- | --- | --- |
| 1 | 每张卡片的核心知识都能在原文找到对应句子 | 删除该卡，或改回原文表述 |
| 2 | 没有出现原文没有的概念、数字、人名、因果、建议 | 删除新增内容 |
| 3 | 任意两张卡片没有在讲同一件事 | 合并 |
| 4 | 每张卡片只包含一个知识点 | 拆分 |
| 5 | 没有为凑数而存在的低信息卡 | 删除，回到步骤 5 |
| 6 | 例子或自测题的信息全部来自原文 | 改为原文例子，或改为不依赖外部信息的自测题 |
| 7 | 标题可独立阅读，不含序号式套话 | 重写标题 |
| 8 | 作者主张没有被写成事实 | 加 `作者主张：` 前缀，并注明原文是否给出论据 |
| 9 | 结尾的总结段、号召段没有单独成卡 | 删除该卡 |
| 10 | 并列枚举没有被逐项拆成低信息卡 | 合并为一张清单卡 |

## 输出格式

默认在对话中直接输出 Markdown，不主动写文件；用户明确要求"存成文件 / 导出"时才写入 `.md` 文件。

```markdown
# 知识卡片：{原文标题或"未提供标题"}

原文约 {字数} 字，提取 {N} 张卡片。

{当 N < 5 时，在此加一行数量说明}

---

## 卡片 1｜{标题}

**核心知识：** {一句话结论，观点型文章加"事实："或"作者主张："}

**简明解释：** {2～4 句}

**例子：** {原文例子}
```

原文没有案例素材时，把最后一行换成自测题加答案要点：

```markdown
**自测：** {问题}

> 参考答案要点：{一句话}
```

多张卡片之间用 `---` 分隔。不要在卡片之间插入总结段、学习建议或对原文的评价——那不属于卡片内容。

原文信息量不足（N < 3）时不出卡片，改用以下结构：

```markdown
# 知识卡片：{原文标题或"未提供标题"}

原文约 {字数} 字。无法生成卡片：原文有效知识点不足 3 个。

## 为什么不出卡片

{逐条说明：哪些内容属重复重述、哪些只有结论没有依据、哪些是号召性语句}

## 原文中可提取的要点

{列出 1～2 条，标明不足以成卡}

## 建议补充的材料

{说明需要补齐哪类信息才能得到可用卡片}
```

## 示例

完整范例（原文片段 + 成品卡片 + 四类常见错误对照）见 `references/card-format.md`。在字段写得过满、标题退化成摘要、或不确定"例子"与"自测"如何取舍时查阅。

## 禁止事项

- 不编造：原文没有的因果、数字、结论、建议一律不写，包括"业内通常认为"这类隐性补写。
- 不改写立场：原文是观点就标为观点，不替作者加强或削弱。
- 不添加外部知识：不补充常识、不纠正原文、不引入其他来源。
- 不把摘要当卡片：卡片必须有可回答的知识点，不是段落缩写。
- 不为凑数注水：信息不足时如实减少数量，这比凑满 5 张更符合需求。
